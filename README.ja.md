ksar-jp
=======

[English README](README.md)

ksar-jp は、Linux・macOS・Solaris の sar の出力をグラフ化するツールです。統計グラフは PDF
ファイルに出力できます。

**ksar-jp は [vlsi/ksar](https://github.com/vlsi/ksar) のフォークです。** vlsi/ksar は、Atomique.net
による [SourceForge 上の kSar](https://sourceforge.net/projects/ksar/) のフォークです。ksar-jp
では、日本語のユーザーインターフェース、日本語で出力された sar ファイルへの対応、エクスポートと
読み込み機能の拡張を追加しています。詳細は [ksar-jp で追加した機能](#ksar-jp-で追加した機能)
を参照してください。

リポジトリ: <https://github.com/paguou329/ksar-jp>

バージョン
----------

バージョンは、ksar-jp のベースになっている元の kSar のバージョンに `-jp` を付けたものです。
たとえば `6.1.0-jp` は kSar 6.1.0 をベースにしています。開発中のビルドには `-SNAPSHOT`
が付きます。

クイックスタート
----------------

必要なもの:

- Java 17 以降

jar をビルドして ([ソースからのビルド](#ソースからのビルド) を参照)、起動します。

```
$ java -jar build/libs/ksar-<バージョン>-all.jar
```

ksar-jp で追加した機能
----------------------

元のプロジェクトに対して、ksar-jp では次の機能を追加しています。

### 国際化 (日本語化)

- すべてのメニュー、ダイアログ、メッセージを、リソースバンドル
  `src/main/resources/net/atomique/ksar/Language/Message*.properties` から読み込みます。既定は
  英語で、`Message_ja.properties` が日本語訳です。
- 表示言語は JVM の既定ロケールに従います。明示する場合は `-Duser.language=en` または
  `-Duser.language=ja` を指定します。`Message_<言語>.properties` を追加すれば、他の言語にも
  対応できます。
- 「自動判定」などの項目は表示だけを翻訳しています。設定に保存される値は言語に依存しないため、
  既存の設定もそのまま使えます。
- PDF と CSV に書き出される文字列は翻訳していません。

### 日本語の sar ファイル

- `2026年10月02日` のような日付と、`13時05分09秒` のような時刻を解釈します。通常の `13:05:09`
  形式が混在していても読めます (形式は 1 行ごとに判定します)。
- 日付形式の選択肢に、日本語の日付形式を追加しました。
- 設定で選んだ日付形式がファイルのヘッダーと合わない場合は、ファイル全行がエラーになる代わりに、
  形式を自動判定します。
- sysstat が日本語で出力する平均・サマリの行は読み飛ばします。

### 複数ファイルの一括読み込み

- 「ファイルから読み込み (複数選択可)...」で、複数のファイルを選択できます。ファイルは名前順に、
  同じデータへ追記して読み込みます。`sa01`、`sa02` のような日別ファイルをまとめて読む用途に
  向いています。
- 読めないファイルはスキップします。「停止」ボタンは、残りのファイルの読み込みも止めます。

### エクスポート

- **PDF フォント**: PDF エクスポートで使うフォントファイル (TrueType / OpenType /
  TrueType Collection) を指定できます。日本語を PDF に出力できます。フォントは PDF
  に埋め込まれます。指定しない場合は組み込みフォントを使います。
- **エクスポートプロファイル**: エクスポートダイアログの「エクスポート設定」欄で、設定に名前を
  付けて保存し、選び直すことができます。プロファイルには次の内容が含まれます。
  - JPG/PNG 画像の幅と高さ
  - PDF の用紙サイズ
  - PDF フォントファイル
  - エクスポートから除外するグラフ

  プロファイルが知らないグラフ (CPU 数が多い別のホストなど) は、エクスポート対象になります。

### 設定

- 設定は、プラットフォームの設定ストア (Windows ではレジストリ) ではなく、カレントディレクトリの
  `ksar.properties` に保存します。エクスポートプロファイルは、その隣の `ksar-profiles`
  ディレクトリに、`<名前>.properties` として 1 つずつ保存します。どちらも UTF-8
  のテキストファイルで、コピーや編集ができます。保存先を変えるには
  `-Dksar.config.dir=<ディレクトリ>` を指定します。
- 元の kSar が設定ストアに保存した設定は、引き継ぎません。
- 起動時に読み込んだ設定が既定値で上書きされ、PDF フォントとホスト履歴が再起動で消える問題を
  修正しました。

### ユーザーインターフェース

- ツリー、グラフ選択、ホスト情報、設定画面で、マウスホイールのスクロール量を増やしました。
  1 ノッチで数ピクセルしか動かない画面がありました。
- 「停止」ボタンを押したあと、次の読み込みがすぐ止まってしまう問題を修正しました。
- バージョン情報に、ksar-jp、リポジトリ、謝辞を表示します。

ソースからのビルド
------------------

必要なもの:

- JDK 17 以降

次のコマンドで、ソースから ksar-jp をビルドして起動できます。

```
$ ./gradlew runShadow
```

または

```
$ ./gradlew shadowJar
$ java -jar build/libs/ksar-<バージョン>-all.jar
```

テストは `./gradlew test` で実行します。

リリース
--------

`master` で Test ワークフローが成功すると、Auto Release ワークフロー
(`.github/workflows/auto-release.yml`) が、`gradle.properties` のバージョン (例: `v6.1.0-jp`)
の名前で GitHub リリースを作成し、`ksar-<バージョン>-all.jar` を添付します。そのバージョンの
リリースが既にある場合は何もしません。新しいリリースを作るには、`gradle.properties`
のバージョンを上げて `master` にマージしてください。
